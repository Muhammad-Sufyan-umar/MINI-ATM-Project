# 🏧 ATM Machine

A simple **ATM Machine simulation project built with Python and OOP concepts**.
This project allows users to log in using a PIN and perform basic banking operations.

## ✨ Features

* 🔐 PIN-based Login
* 💰 Check Current Balance
* 💵 Deposit Money
* 🏧 Withdraw Money
* 🔑 Change PIN
* 🚪 Exit the Program

## 🛠️ Concepts Used

* Python
* Object-Oriented Programming (OOP)
* Classes and Objects
* Methods
* Conditional Statements
* Loops
* User Input
* Encapsulation

## ▶️ How to Run

1. Clone this repository:

```bash
git clone <your-repository-url>
```

2. Open the project folder:

```bash
cd ATM
```

3. Run the Python file:

```bash
python main.py
```
